# 苍龙逐日：数据差异

这份说明整理了实际游玩发现的剧情、物品和攻略差异。以下“原始版”指提供的苍龙逐日复刻数据，“修正版”指本次提供的数据修复。

## 已确认并提供修复的数据问题

| 内容 | 原始版的表现 | 修正版的表现 |
| --- | --- | --- |
| 闯王宝藏 | 其中一处宝藏山洞，对门使用闯王军刀没有反应；其他宝藏山洞正常。 | 对应山洞也能直接用军刀开门。其他物品不能代替军刀，开门不会消耗军刀。 |
| 灵鹫宫壁画 | 按攻略看完七幅壁画后，可能拿到天山折梅手，却漏掉八荒六合唯我独尊功；另一处宝箱还会再给一次天山折梅手。 | 看完七幅不同壁画后，正确获得八荒六合唯我独尊功。虚竹在队时，保留相应学会武功和增加资质的奖励；独立宝箱仍给天山折梅手。重复看壁画或领取奖励不会重复获利。 |
| 须弥山神掌、七伤拳谱、大剪刀刀法 | 名称夹有多余换行，显示不整齐，也影响按名称查找。 | 仅清除多余换行，保留物品原名、用途和数值。“大剪刀刀法”没有另行改名。 |

宝藏和壁画修复应从新游戏开始体验。旧存档中已经记录的开门、壁画和领奖状态不会自动更新，也不会自动补发漏掉的奖励。

## 已修复的复刻程序问题

这些改动由程序统一处理，图形版和 MCP 使用相同结果。

| 内容 | 修复前 | 修复后 |
| --- | --- | --- |
| 轻功入场条件 | 某类需要轻功的场景，没有正确检查队伍能力。 | 队伍中至少一名队员轻功超过 70，才满足这类入场条件；70 仍不满足。 |
| 战斗移动 | 部分水域、敌人身边的停步限制，以及分段移动的范围判断与稳定参考版不一致。 | 恢复相应地形和移动限制，不能通过拆分移动多走，也不会在找不到合法路线时错误移动。 |
| 交出已装备的物品 | 交出最后一把金蛇剑等装备后，角色仍可能保持装备状态。 | 最后一件装备交出后，角色同时卸下它；仍有剩余同类装备时保留原有处理。 |
| 高抗毒角色受到暗器攻击 | 抗毒超过 100 时，带毒暗器可能让中毒数值变成负数。 | 高抗毒不会产生负中毒，也不会因为挨打而出现异常解毒。 |
| 背包满、名称显示和异常剧情数据 | 极端情况下可能读取错误内容或崩溃。 | 补充边界检查，名称不会串入相邻内容，异常剧情数据会被拦截。 |

交出装备和暗器中毒两项，在稳定参考版中也能出现。本次一并修正。

## 攻略与实际游戏不同，但未改动的内容

| 内容 | 实际游玩的结果 | 当前处理 |
| --- | --- | --- |
| 狄云入队 | 品德达到 70 即可满足该项要求，攻略写得更严格。 | 按实际游戏保留 70 的门槛。 |
| 华山最后的单人比武 | 实际要连续面对 18 名对手，攻略写的是 15 名。 | 保留实际的 18 场。 |
| 鸳鸯刀放刀 | 身上已有对应刀时，使用罗盘等无关物品也可能放入那把刀；正常使用两把刀、两种先后顺序都能完成。 | 已确认这种表现，但无法确定是否为作者有意简化操作，暂不改变。 |
| 长乐帮、雪山入口 | 出生位置看起来与障碍重叠，但实际能走开、继续剧情和离开。 | 没有发现困住玩家的问题，不修改入口。 |
| 明霞岛位置 | 按攻略给出的位置附近，可以正常接近并进入。 | 不修改坐标。 |
| 玄冰碧火酒相关疑点 | 没有证实正常游玩会遇到无法使用酒的情况。 | 暂不作为已确认问题修复。 |

## 已经玩过的范围

原复刻规则下，已完成正线和另一套主要分支的十四天书流程，并实际到达结局；四种开局对应的隐藏武功也分别取得。宝藏开门和灵鹫宫壁画修复，另有从新游戏开始的流程验证。

这些结果覆盖了攻略中的主要路线和重点支线，不代表所有对话顺序、队伍组合及战术都已经穷尽。改用苍龙 1.2 原版数值后，还需要重新进行完整流程验证。
