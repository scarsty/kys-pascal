# 苍龙逐日：Z.dat 规则差异

本次增加了“苍龙 1.2 原版规则”，用于选择原版的升级成长和战斗数值。下面对比的是提供的复刻版配置与苍龙 1.2 原版规则。未选择新规则时，继续使用原复刻规则。

## 等级和成长

| 内容 | 原复刻规则 | 苍龙 1.2 原版规则 |
| --- | --- | --- |
| 等级上限 | 当前配置为 60 级。 | 30 级。 |
| 升级经验 | 每升一级扣掉该级所需经验。 | 累计经验保留；达到 52,000 总经验时升到 30 级。 |
| 一次连升多级 | 每一级分别处理成长。 | 先抽一次每级成长，再乘以这次提升的等级数。 |
| 攻击、轻功、防御 | 使用复刻版的资质算法；当前配置取最大成长。 | 根据资质随机成长，三项使用同一次成长结果，见下表。 |
| 生命成长 | 由角色的生命成长基础决定，并附加小幅随机值。 | 同样取决于角色基础，但改用原版的三个成长档位。例如基础为 3 的角色，每级可能增加 9、12 或 15 点生命。 |
| 内力成长 | 使用复刻版的成长幅度。 | 与本次攻击等属性的成长配对：攻击等属性涨得越多，内力涨得越少；每级增加 12～32 点，具体范围受资质影响。 |
| 医疗、用毒、解毒及武器能力 | 已有相关能力通常都会随升级成长，并受复刻配置的上限限制。 | 医疗、用毒、解毒、拳掌、御剑、耍刀在原值超过 20 时，才有机会增加 0～2 点；暗器即使从 0 开始也能成长。一次连升多级，这些小幅成长只结算一次。 |
| 抗毒、特殊兵器 | 可能随升级成长。 | 不随升级成长。 |
| 属性上限 | 采用复刻版配置；当前多数能力上限为 999。 | 升级时医疗、用毒、解毒封顶 100；攻击、轻功、防御及上述武器能力没有统一的 100 点升级封顶。吃药、练书的上限另按各自规则处理。 |
| 生命、内力、体力上限 | 当前配置为 999、9999、100。 | 默认同样为 999、9999、100。 |

苍龙 1.2 每级攻击、轻功、防御的成长范围：

| 资质 | 每项每级增加 |
| --- | --- |
| 低于 30 | 1～2 |
| 30～49 | 1～3 |
| 50～69 | 1～4 |
| 70～89 | 1～5 |
| 90 及以上 | 1～6 |

例如，一次升两级，抽到每级加 3，则攻击、轻功、防御各加 6。升级后仍会补满生命、内力和体力，并清除受伤与中毒。

## 战斗中能感受到的变化

| 内容 | 改用苍龙 1.2 原版规则后的表现 |
| --- | --- |
| 武功伤害 | 攻防权重、装备加成、武器与招式搭配、武学常识的作用均改为原版数值。同样的面板和招式，伤害可能明显不同。 |
| 拳掌、御剑等能力 | 不再直接作为该伤害计算中的额外攻防加成；修炼要求等用途仍然存在。 |
| 受伤与体力 | 攻击者受伤不再按复刻公式直接打折；体力和对手的受伤程度会影响本次伤害。 |
| 距离和低伤害 | 远距离衰减及打不动高防敌人时的保底伤害，改按原版处理。 |
| 内力不足 | 会降低本次武功的实际威力档次；即使没有内力，也能使出最低档攻击。 |
| 左右互搏 | 一次出手即使打两次，也只消耗 3 点体力；原复刻规则通常每次攻击各扣 3 点。 |
| 吸内力武功 | 吸取量、自己恢复的内力，以及最大内力增长，采用原版各自的数值。对手内力已经为零，也不一定阻止自己的恢复和成长。 |
| 用毒、解毒、医疗 | 改用原版效果与战斗经验。战斗中通常消耗 2 点体力；医疗还要求施术者至少有 50 点体力。 |
| 战斗外医疗 | 同样要求至少 50 点体力，并消耗 2 点；战斗外解毒仍不消耗体力。原复刻规则下，这两项在战斗外都免费。 |
| 暗器 | 重新考虑使用者暗器能力、物品、对手受伤程度和抗毒，伤害与附毒可能与复刻版差别较大。 |
| 休息 | 改为较小的随机恢复量；体力不足时不能靠一次休息同时恢复生命和内力。 |
| 每轮受伤和中毒 | 扣血方式改为原版处理。伤势和中毒管理的重要性会改变。 |
| 战斗经验 | 命中、击倒对手、医疗和用毒等行为的经验改为原版算法，升级速度也会随之变化。整场战斗的额外奖励分配仍沿用复刻版。 |

原版还保留了一些不直观的表现：吸内力招式的耗内力可能受之前攻击影响；刚好把对手打到零生命，与打出超过剩余生命的伤害，额外经验可能不同。本次按原版保留，未另行调整平衡。

## 可以调整的内容

原复刻规则与苍龙 1.2 原版规则可以选择；升级成长和战斗数值也可以分别选择。

在原版规则基础上，可以自定义等级、生命、内力和体力上限，各级经验要求，以及生命、内力、攻击、轻功、防御的成长倍率。提高等级上限时，需要同时提供完整的后续升级经验。

更换经验规则或成长配置后，应开始新游戏。旧角色已经获得的经验和属性不会自动换算成另一套规则。

## 当前验证范围

已逐项对照原版验证升级、伤害和恢复等数值，并通过新角色练功、学武、获胜及保存后继续游戏的检查。此前完整的攻略通关使用原复刻规则；苍龙 1.2 原版数值还没有完成一次新的完整通关。

人物初始数据、剧情、物品与练书规则、自动战斗策略和移动顺序等仍沿用复刻版。自动战斗仍可能反复选择吸内力招式，遇到久攻不下时需要切换手动。因此，这次提供的是原版成长与战斗数值的选择，并非整个 DOS 游戏的完整还原。
