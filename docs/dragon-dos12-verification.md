# 苍龙 1.2 DOS 规则核验与修复

核验对象为原始安装包解出的 `Z.dat`，SHA-256：

```text
60ff7e91d7be7a848242e2ddc2ef105b906e160e19f3086bf13ff55d8e951928
```

本机原始文件位于 `tmp/reverse/dragon-dos12/base/Z.dat`。同目录下
`patch/PatchForCLZR/z.dat` 是另一份补丁程序，哈希不同，本次未用它作为依据。
核验不会改写这两份程序。

## 方法

`tools/verify_dragon_dos12.py` 验证完整文件哈希，然后使用 Unicorn 模拟执行原始
LE 可执行文件第二对象中的 x86 函数或相关代码块。随机函数替换为指定抽样，栈检查
函数替换为空操作；成长、伤害、资源修改、条件跳转均执行原始机器码。
这属于针对原始程序的隔离执行核验，没有通过 DOSBox 进行完整界面操作。

安装 Python 依赖 `unicorn` 后，在仓库根目录运行：

```powershell
python tools/verify_dragon_dos12.py tmp/reverse/dragon-dos12/base/Z.dat --output tmp/validation/dragon-dos-original-issues.json
```

以下地址均为 LE 第二对象内偏移，对应文件位置为该偏移加 `0x19a00`。
脚本只接受上述 SHA-256 的程序，避免将这些固定地址误用于其他版本。

## 原版结果与处理

| 问题 | 原版代码位置与可重复结果 | 本项目处理 |
| --- | --- | --- |
| 连升多级漏算能力 | `0x1b6be` 升级函数：1 级累计取得 750 经验升至 6 级；能力随机抽样固定为 1 时，医疗和暗器仍只增加 1。 | 每级独立抽样、完整成长；相同随机序列下，连升与分次升级结果一致。 |
| 吸内力耗蓝串用旧档次 | `0x18520..0x18551` 耗蓝代码读取全局 `0xc6ec2`；相同当前内力 100、耗蓝参数 10，缓存档次为 0、2、10 时分别消耗 0、10、50。`0x19282` 在生命伤害函数中写入这个缓存。 | 本次施法开始时根据当前角色与招式计算成本，结算不读取旧缓存，也不受本次恢复内力影响。 |
| 空内力目标提供收益 | `0x195ec` 吸内力函数：目标内力为 0、恢复参数为 20、指定上限成长抽样为 4，施术者仍恢复 20 内力并增加 4 点上限。 | **按要求保留**原版吸内力效果，恢复和永久上限成长不受实际吸取量约束；独立修复施法耗蓝。 |
| 暗器能力削弱附毒 | `0x1a73b..0x1a839` 附毒代码：毒性 100、抗毒 0，暗器能力 20 与 80 分别增加 20 与 5 点中毒。 | 去掉附毒公式对暗器能力的减项；保留物品毒性、抗毒、免疫与中毒上限。 |
| 无毒暗器施毒或解毒 | 同一代码块：毒性 0，原有中毒 10，指定随机抽样可使中毒增加 4 或减少 4。 | 无毒暗器不修改中毒值。 |
| 恰好归零漏发奖励 | `0x19493..0x194ee`：对 5 级敌人固定造成 10 伤害，原有 10 血时经验为 2，原有 9 血时为 52。`0x194d4` 的 `jge` 跳过了恰好为零的奖励。 | 两种击倒都奖励 52，其中 2 为伤害经验，50 为击倒经验。 |
| 回合扣血反而保命 | `0x1c56d..0x1c671`：原有 10 血，中毒值 10 与 11 时分别剩 0 与 1 血。`0x1c656` 的 `jge` 漏掉了零生命。 | 对存活角色统一保留至少 1 血，并排除已倒下角色。 |
| 破防与保底伤害不连续 | `0x1938e..0x19493`：总攻击 300、体力 90、距离 1、伤势和随机扰动均为 0，防御 99 与 100 时分别造成 8 与 36 伤害。 | **按要求保留**原版公式及分支；原生回归测试固定验证 8 与 36。 |

## 回归验证

原版机器码核验与修复后的 C++ 测试分别运行：前者记录历史行为，后者要求六项修复生效，并固定验证两项保留的原版机制。

```powershell
cmake --build bin-c/build --config Release --parallel 6
ctest --test-dir bin-c/build -C Release --output-on-failure
```

`bin-c/tests/dragon_rules_tests.cpp` 覆盖逐级成长与批量成长的一致性、成长门槛和上限、
施法前成本、旧缓存隔离、未命中与群攻耗蓝、暗器附毒、击倒经验、非致死回合伤害，
以及刻意保留的空内力目标收益和原版伤害跳变。

旧 V4 检查点中的耗蓝缓存字段仍可读取与保存，但不再参与玩法计算。规则查询返回
逐级成长，招式查询不再标记耗蓝依赖旧缓存。现有存档中已经漏掉的成长不会追溯补发。
