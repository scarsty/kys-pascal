# 苍龙逐日

苍龙逐日统一使用 DOS 1.2 的战斗、成长和初始属性，允许自定义成长随机模式和数值。准备游戏数据后，在模组配置中设置 `[system] MODVersion=12` 即可；苍龙不再提供复刻或混搭规则。其他 MOD 的规则保持不变。

苍龙的规则选择、名称兼容、初始角色设置、场景命名策略和标题默认值由 `bin-c/mods/dragon.cpp` 统一提供；引擎和各前端使用同一份已解析的 MOD 定义。

其他 MOD 也分别拥有自己的定义文件，完整对照见 [C++ MOD 定义](MODs.md)。

## 苍龙 1.2 规则与成长自定义

### 新游戏初始属性

初始属性采用 DOS 1.2 的抽取方式：内力上限为 21～40，攻击、轻功、防御及各项能力（包括抗毒）为 21～30，生命成长基础为 3～7。初始生命上限为 `29 + 3 × 生命成长基础 × 等级`，1 级时为 38～50。资质分三档抽取：20% 在 30～64，60% 在 60～79，20% 在 75～94；范围有重叠。

保留复刻版的「小小猪」「见贤思齐」特殊姓名属性，作为本实现相对 DOS 的明确扩展。新游戏先完整抽取一次 DOS 初始属性，再应用姓名预设并显示最终属性；特殊姓名直接确认，普通姓名可以重抽。姓名预设未覆盖的抗毒仍取本次 DOS 抽取值，不继承资源中的初始值。姓名在匹配前统一转换为繁体。

### 等级与成长

默认等级上限为 **30 级**，经验累计保留，达到 **52,000 总经验**时升到 30 级。

原版规则按资质随机决定攻击、轻功和防御的成长，三项使用同一次随机结果：

| 资质 | 攻击、轻功、防御每项每级增加 |
| --- | --- |
| 低于 30 | 1～2 |
| 30～49 | 1～3 |
| 50～69 | 1～4 |
| 70～89 | 1～5 |
| 90 及以上 | 1～6 |

可在「系统设置 → 升级成长」选择原版、固定随机、平均、最大四档。默认「原版」忠实保留 DOS 的连升共抽与能力只结算一次；其他三档每级独立完整结算，与分次升级的结果一致。「最大」另选三维优先或内力优先，避免把互斥的最大值拼在一起。「平均」会保存三维的半点余数；符合成长门槛的兵器和医疗等能力每级固定 +1。这些选项只改变升级成长，战斗随机数、武功熟练度、吸内力和初始属性仍遵循各自的 DOS 行为。

其他成长变化如下：

| 属性 | 苍龙 1.2 原版规则 |
| --- | --- |
| 生命 | 按角色的生命成长基础，从三个档位中随机取值。例如基础为 3 的角色，每级增加 9、12 或 15 点。 |
| 内力 | 每级增加 12～32 点，具体范围受资质影响；本次攻击、轻功、防御成长越高，内力成长越低。 |
| 医疗、用毒、解毒、拳掌、御剑、耍刀 | 原值超过 20 才成长；随机档为 0～2 点，平均档 +1，最大档 +2。原版档连升仍只结算一次。 |
| 暗器 | 从 0 开始也能成长，数值和结算次数同上述能力。 |
| 抗毒、特殊兵器 | 不随升级成长。 |

升级时，医疗、用毒、解毒最高增长到 100；攻击、轻功、防御及可成长的武器能力不受统一的 100 点上限限制。吃药和练书的属性上限按各自规则处理。生命、内力和体力上限默认分别为 999、9999 和 100。

升级后会补满生命、内力和体力，并清除受伤与中毒。

### 战斗变化

| 内容 | 苍龙 1.2 原版规则 |
| --- | --- |
| 武功伤害 | 攻防权重、装备加成、武器与招式搭配、武学常识、距离衰减和保底伤害均采用原版数值。同样的属性和招式，伤害可能明显不同。 |
| 武器能力 | 拳掌、御剑等能力不再直接提供武功伤害计算中的额外攻防加成，仍用于判断修炼要求。 |
| 受伤与体力 | 攻击者受伤不再按复刻公式直接削减伤害；体力和对手的受伤程度会影响伤害。 |
| 内力不足 | 降低武功的实际威力档次；没有内力时仍能使出最低档攻击。 |
| 左右互搏 | 一次出手即使攻击两次，也只消耗 3 点体力；复刻版通常每次攻击各扣 3 点。 |
| 吸内力武功 | 保留原版的吸取、恢复和上限成长算法。即使对手内力为零，自身仍可能恢复内力或提高内力上限。耗蓝按本次施法前的角色与招式计算。 |
| 用毒、解毒、医疗 | 效果和获得的战斗经验采用原版算法，战斗中通常消耗 2 点体力；医疗还要求施术者至少有 50 点体力。 |
| 战斗外医疗 | 要求至少有 50 点体力，并消耗 2 点；战斗外解毒不消耗体力。 |
| 暗器 | 保留原版伤害算法，受使用者暗器能力、物品与对手伤势影响。附毒取决于物品毒性与对手抗毒；提高暗器能力不削弱附毒，无毒暗器不改变中毒。 |
| 休息 | 恢复量较小且随机；体力不足时，一次休息不能同时恢复生命和内力。 |
| 受伤与中毒 | 保留原版每轮扣血量，伤害至少保留 1 点生命。 |
| 战斗经验 | 保留原版经验数值，修正恰好打到 0 血时遗漏击倒奖励的问题。 |


### 配置与存档兼容

在模组的 `kysmod.ini` 中选择苍龙并配置成长模式，也可在游戏设置中调整成长模式：

```ini
[system]
MODVersion=12

[rules]
growth_mode=original
growth_max_priority=stats
```

旧的 `[rules] profile=dragon_dos12` 仍是苍龙的兼容别名：省略 `MODVersion` 时会同时选择苍龙的身份、数据兼容和 DOS 规则；如果已填写其他 `MODVersion`，程序会报告配置冲突。苍龙配置中旧的 `profile=remake`、`profile=legacy` 或复刻 `progression` / `combat` 选择会报错，请删除这些旧设置。`progression=dragon_dos12` 和 `combat=dragon_dos12` 只作为同一完整 MOD 的冗余别名保留，不再独立选择组件。

`growth_mode` 可选 `original`、`fixed_random`、`average` 或 `maximum`。固定随机按本局种子、角色、目标等级和成长项目确定结果，不消耗战斗随机数；读档或改变升级顺序不会重抽。最大档的 `growth_max_priority` 可选 `stats`（三维优先）或 `mp`（内力优先）。切换模式只影响未来升级，不补发历史成长。

仍可用 `[rules]` 的 `hp_growth_factor`、`mp_growth_factor`、`attack_growth_factor`、`speed_growth_factor`、`defence_growth_factor` 调整成长系数，或用 `max_level`、`max_hp`、`max_mp` 等调整上限。提高等级上限超过 30 时，需用 `xp_thresholds` 为每个后续等级提供递增的累计经验门槛。

原有苍龙复刻存档的文件结构仍能读取，但经验与成长语义已统一为 DOS；本次调整不会重算历史属性或把复刻经验转换为累计经验。原来使用复刻规则的玩家应从新游戏开始。

固定随机的种子和平均模式的半点余数保存在角色记录原有的未使用字段中，R 文件长度和字段偏移不变。角色 0 的个人物品栏用于保存种子；已有物品时不会覆盖，固定随机会报告冲突。旧存档使用角色数据的确定性哈希初始化种子。其他编辑器如果清除这些字段，可能丢失种子或余数。原 DOS 角色段读写的字段保留曾通过隔离机器码执行检查，但这不等同于完整游戏或所有存档编辑器的兼容性验证。

## 回归测试

`bin-c/tests/dragon_rules_tests.cpp` 覆盖成长模式、存档状态及部分战斗规则。配置好原生构建后运行：

```powershell
cmake --build bin-c/build --config Release --parallel 6
ctest --test-dir bin-c/build -C Release --output-on-failure
```
