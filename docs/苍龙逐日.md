# 苍龙逐日

本页介绍程序修复和可选的“苍龙 1.2 原版规则”。引擎默认使用复刻版规则；使用苍龙规则需准备游戏数据并在模组配置中启用。

## 剧情与物品数据

以下问题曾在修复版游戏数据中处理；本仓库不包含这些数据，也不会自动修改游戏数据。

| 内容 | 修复内容 |
| --- | --- |
| 闯王宝藏 | 修复一处宝藏山洞无法用闯王军刀开门的问题。 |
| 灵鹫宫壁画 | 修正看完七幅壁画后的奖励：由错给《天山折梅手》改为获得《八荒六合唯我独尊功》。 |
| 物品名称 | 清除须弥山神掌、七伤拳谱、大剪刀刀法名称中的多余换行，使名称正常显示。 |

## 程序修复

| 内容 | 修复内容 |
| --- | --- |
| 轻功入场条件 | 正确检查队伍轻功：至少一名队员轻功超过 70，才能进入有此要求的场景。 |
| 战斗移动 | 修正部分水域的通行、敌人身边的停步限制和分段移动范围，避免拆分移动多走或无路可走时错误移动。 |
| 交出装备 | 交出最后一件已装备的物品时，角色会同时卸下它。 |
| 带毒暗器 | 修复抗毒超过 100 时中毒数值可能变成负数、受到攻击反而异常解毒的问题。 |
| 连续升级 | 提供四档成长；固定随机、平均、最大三档逐级完整结算，原版档保留 DOS 的连升共抽与能力只结算一次。 |
| 吸内力耗蓝 | 每次根据当前角色、当前招式及施法前的内力计算，不再受此前其他角色的攻击影响；未命中也正常结算。 |
| 暗器附毒 | 暗器能力提高不再削弱附毒；无毒暗器不改变目标已有的中毒值。 |
| 击倒经验 | 敌人生命恰好归零时，也会获得与打成负数相同的击倒奖励。 |
| 回合扣血 | 受伤和中毒的回合伤害至少保留 1 点生命；已经倒下的角色不再处理回合扣血。 |
| 稳定性 | 修复背包已满、名称显示及异常剧情数据可能引起的读取错误或崩溃。 |

部分苍龙规则问题曾通过隔离执行原始安装包 `Z.dat` 的机器码核对；随机抽样受控，未进行完整 DOSBox 界面验证。原版伤害公式及空内力目标仍可提供收益的行为刻意保留。

## 可选的苍龙 1.2 原版规则

### 等级与成长

原版规则的等级上限为 **30 级**，经验累计保留，达到 **52,000 总经验**时升到 30 级。复刻版默认上限为 60 级，每次升级会扣除该级所需经验。

原版规则按资质随机决定攻击、轻功和防御的成长，三项使用同一次随机结果：

| 资质 | 攻击、轻功、防御每项每级增加 |
| --- | --- |
| 低于 30 | 1～2 |
| 30～49 | 1～3 |
| 50～69 | 1～4 |
| 70～89 | 1～5 |
| 90 及以上 | 1～6 |

可在「系统设置 → 升级成长」选择原版、固定随机、平均、最大四档。默认「原版」忠实保留 DOS 的连升共抽与能力只结算一次；其他三档每级独立完整结算，与分次升级的结果一致。「最大」另选三维优先或内力优先，避免把互斥的最大值拼在一起。「平均」会保存三维的半点余数；符合成长门槛的兵器和医疗等能力每级固定 +1。复刻版成长仍使用原有开关。

其他成长变化如下：

| 属性 | 苍龙 1.2 原版规则 |
| --- | --- |
| 生命 | 按角色的生命成长基础，从三个档位中随机取值。例如基础为 3 的角色，每级增加 9、12 或 15 点。 |
| 内力 | 每级增加 12～32 点，具体范围受资质影响；本次攻击、轻功、防御成长越高，内力成长越低。 |
| 医疗、用毒、解毒、拳掌、御剑、耍刀 | 原值超过 20 才成长；随机档为 0～2 点，平均档 +1，最大档 +2。原版档连升仍只结算一次。 |
| 暗器 | 从 0 开始也能成长，数值和结算次数同上述能力。 |
| 抗毒、特殊兵器 | 不随升级成长。 |

升级时，医疗、用毒、解毒最高增长到 100；攻击、轻功、防御及可成长的武器能力不受统一的 100 点上限限制。吃药和练书的属性上限按各自规则处理。生命、内力和体力上限默认分别为 999、9999 和 100。

升级后会补满生命、内力和体力，并清除受伤与中毒。

### 战斗变化

| 内容 | 苍龙 1.2 原版规则 |
| --- | --- |
| 武功伤害 | 攻防权重、装备加成、武器与招式搭配、武学常识、距离衰减和保底伤害均采用原版数值。同样的属性和招式，伤害可能明显不同。 |
| 武器能力 | 拳掌、御剑等能力不再直接提供武功伤害计算中的额外攻防加成，仍用于判断修炼要求。 |
| 受伤与体力 | 攻击者受伤不再按复刻公式直接削减伤害；体力和对手的受伤程度会影响伤害。 |
| 内力不足 | 降低武功的实际威力档次；没有内力时仍能使出最低档攻击。 |
| 左右互搏 | 一次出手即使攻击两次，也只消耗 3 点体力；复刻版通常每次攻击各扣 3 点。 |
| 吸内力武功 | 保留原版的吸取、恢复和上限成长算法。即使对手内力为零，自身仍可能恢复内力或提高内力上限。耗蓝按本次施法前的角色与招式计算。 |
| 用毒、解毒、医疗 | 效果和获得的战斗经验采用原版算法，战斗中通常消耗 2 点体力；医疗还要求施术者至少有 50 点体力。 |
| 战斗外医疗 | 要求至少有 50 点体力，并消耗 2 点；战斗外解毒不消耗体力。 |
| 暗器 | 保留原版伤害算法，受使用者暗器能力、物品与对手伤势影响。附毒取决于物品毒性与对手抗毒；提高暗器能力不削弱附毒，无毒暗器不改变中毒。 |
| 休息 | 恢复量较小且随机；体力不足时，一次休息不能同时恢复生命和内力。 |
| 受伤与中毒 | 保留原版每轮扣血量，伤害至少保留 1 点生命。 |
| 战斗经验 | 保留原版经验数值，修正恰好打到 0 血时遗漏击倒奖励的问题。 |


### 配置与存档兼容

在模组的 `kysmod.ini` 中选择规则和成长模式，也可在游戏设置中调整成长模式：

```ini
[rules]
profile=dragon_dos12
growth_mode=original
growth_max_priority=stats
```

`growth_mode` 可选 `original`、`fixed_random`、`average` 或 `maximum`。固定随机按本局种子、角色、目标等级和成长项目确定结果，不消耗战斗随机数；读档或改变升级顺序不会重抽。最大档的 `growth_max_priority` 可选 `stats`（三维优先）或 `mp`（内力优先）。切换模式只影响未来升级，不补发历史成长。

固定随机的种子和平均模式的半点余数保存在角色记录原有的未使用字段中，R 文件长度和字段偏移不变。角色 0 的个人物品栏用于保存种子；已有物品时不会覆盖，固定随机会报告冲突。旧存档使用角色数据的确定性哈希初始化种子。其他编辑器如果清除这些字段，可能丢失种子或余数。原 DOS 角色段读写的字段保留曾通过隔离机器码执行检查，但这不等同于完整游戏或所有存档编辑器的兼容性验证。

## 回归测试

`bin-c/tests/dragon_rules_tests.cpp` 覆盖成长模式、存档状态及部分战斗规则。配置好原生构建后运行：

```powershell
cmake --build bin-c/build --config Release --parallel 6
ctest --test-dir bin-c/build -C Release --output-on-failure
```
